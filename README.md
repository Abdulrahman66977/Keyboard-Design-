        🧮 Dynamic Calculator Application

 Overview

This project is a functional web-based calculator application that mimics a standard numeric keypad. It is built entirely with vanilla JavaScript, HTML, and CSS, demonstrating core frontend skills in DOM manipulation, event handling, and dynamic styling.

It is a great example of transforming a UI design project into a practical, interactive utility.

 ✨ Key Features Implemented

1. Real-time Keyboard Input: The application is fully responsive to physical keyboard input (`0-9`, `+`, `-`, `*`, `/`, `=`, `Backspace`), providing a desktop-like user experience.
2. CSS Keyframe Animation: Utilizes a CSS `@keyframes` animation (`border-rotate`) to create a dynamic, changing border color on the calculator container, adding a modern visual flair.
3. Standard Arithmetic Operations: Supports Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
4. Error Handling: Implements a `try...catch` block in JavaScript to prevent the application from crashing and displays an 'Error' message for invalid expressions.
5. CSS Grid Layout: Uses CSS Grid to efficiently arrange the calculator keys into a classic 4-column layout.
